SystemVerilog Interview Questions and Practice

SystemVerilog is central to modern RTL and verification interviews. Preparation should cover both synthesizable language constructs and the verification features used to build robust testbenches.

High-value SystemVerilog topics

always_comb and always_ff

Know what each construct expresses, how tools check intent, and why separating combinational and sequential logic makes RTL easier to review and verify.

Interfaces and modports

Understand how interfaces bundle related signals and how modports constrain the directions and views available to different components.

Data types

Be ready to discuss 2-state versus 4-state types, packed versus unpacked arrays, enums, structs and when each is appropriate in RTL or verification code.

Assertions

SystemVerilog Assertions are often tested alongside RTL. Understand clocked properties, implication, delays, repetition and reset-aware checks. See the handshake assertion problem.

Common interview questions

  • What is the difference between always_comb and always_ff?
  • Why would you use an interface?
  • What is the difference between packed and unpacked arrays?
  • When should an enum or struct be used?
  • How would you assert that a valid request eventually receives a handshake?

Practise

Test your understanding with the always_comb vs always_ff problem and the SystemVerilog interface problem.
