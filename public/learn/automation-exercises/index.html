Inspect a simulation run

Practise reading simulator output, identifying the first failing check, and choosing the next useful diagnostic step.

Beginner10–15 minLog analysis
Your task
  1. 1Inspect the files
    Open the run log and test configuration.
  2. 2Find the first failure
    Separate the first meaningful error from follow-on messages.
  3. 3Choose the next action
    Identify a focused diagnostic step.
Success criteria
  1. ✓Identify the first failing check.
  2. ✓Recognise likely secondary errors.
  3. ✓Choose a targeted diagnostic action.
Automation mode
This exercise uses read-only logs and configuration. The check button is a UI prototype; it does not execute a simulator, shell, or Python process.
