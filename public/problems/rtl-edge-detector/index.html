Rising Edge Detector RTL Interview Problem

Generate a one-cycle pulse whenever an input transitions from 0 to 1. Register the previous input value and assert rise for exactly one cycle.

Examples

  • Signal 0→1 → rise=1 for one cycle.
  • Signal remains 1 → rise=0.

What this tests

Synchronous edge detection, registered state and reset semantics.
