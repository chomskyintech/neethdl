Shift Register RTL Interview Problem

Design a parameterized synchronous shift register. On each rising edge, shift stored bits toward the MSB and insert din at bit 0.

Examples

  • Reset → dout=0.
  • dout=8'b00000001, din=0 → next dout=8'b00000010.

Constraints

Parameterize width, use synchronous active-high reset, and shift only when shift_en is high.

What this tests

Sequential RTL, shifting, parameters and reset handling.
