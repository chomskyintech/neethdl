Synchronous FIFO RTL Interview Problem

Implement a synchronous parameterized FIFO with ready/valid-style enqueue and dequeue controls. Maintain ordering and correctly generate full and empty status.

Examples

  • After reset, empty=1.
  • Write A then read → A.

Constraints

  • Single clock domain.
  • Do not read when empty or write when full.

What this tests

FIFO pointers, memory, occupancy, handshaking and sequential RTL.
