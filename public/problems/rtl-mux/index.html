2:1 Multiplexer RTL Interview Problem

Design a synthesizable 2:1 multiplexer in SystemVerilog. This tests basic combinational RTL, conditional selection and clean synthesizable coding.

Task

Implement y so that it selects a when sel is 0 and b when sel is 1.

Examples

  • a=0, b=1, sel=0 → y=0
  • a=0, b=1, sel=1 → y=1

Constraints

  • Use synthesizable SystemVerilog.
  • Do not use delays.

What this tests

Combinational logic, mux implementation, synthesizability and SystemVerilog RTL style.
