Parameterized Counter RTL Interview Problem

Build a parameterized synchronous up-counter with reset. Increment count on each rising clock edge and synchronously clear it when reset is high.

Examples

  • reset=1 → count=0
  • reset=0, count=7 → next count=8

Constraints

  • Parameterize the width.
  • Reset is synchronous and active high.

What this tests

Sequential RTL, parameters, clocked state and reset semantics.
