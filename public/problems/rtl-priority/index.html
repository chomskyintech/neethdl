Priority Encoder RTL Interview Problem

Design an 8-to-3 priority encoder where bit 7 has the highest priority. Return the index of the highest set input bit and a valid flag.

Examples

  • in=8'b00101000 → index=5, valid=1
  • in=0 → valid=0

Constraints

  • Bit 7 has highest priority.
  • valid must be 0 when all inputs are 0.

What this tests

Combinational RTL, priority logic and SystemVerilog coding style.
