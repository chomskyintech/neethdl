4-Request Priority Arbiter RTL Interview Problem

Build a fixed-priority arbiter for four requesters. Grant exactly one requester, with request 3 highest priority and request 0 lowest.

Example

req=4'b0101 → grant=4'b0100; req=0 → grant=0.

What this tests

Priority logic, one-hot grants, combinational RTL and corner cases.
